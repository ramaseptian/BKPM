# BKPM Acara 10 - Inheritance & Repository Pattern

Implementasi studi kasus Manajemen Data Mahasiswa sesuai BKPM Acara 10.

## Cara menjalankan
1. Jalankan Apache dan MySQL pada XAMPP/Laragon.
2. Import `database/acara_10.sql` melalui phpMyAdmin.
3. Pastikan `config/database.php` sesuai konfigurasi MySQL lokal.
4. Letakkan folder `acara_10` di `C:\xampp\htdocs`.
5. Buka `http://localhost/acara_10/public/?page=mahasiswa`.
6. Uji tampil, tambah, ubah, dan hapus data.
